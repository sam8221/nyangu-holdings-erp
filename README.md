# Nyangu Holdings ERP

Web-based ERP starter structure for Nyangu Holdings.

## Stack
- Frontend: React + Vite
- Backend: Python + FastAPI
- Database: PostgreSQL
- ORM: SQLAlchemy
- Authentication: JWT + RBAC

## Status
The backend's Phase 1 is done: configuration, database and migrations, JWT authentication,
RBAC, and user, role and permission management, with a passing test suite. Setup, API and
security details are in [backend/README.md](backend/README.md).

The frontend is still a placeholder shell (login and dashboard pages only).
